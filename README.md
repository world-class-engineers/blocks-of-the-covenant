# Blocks of the Covenant

A Minecraft Bedrock Add-On

## Structure

- `behavior_packs/` - Behavior pack with scripts and data
- `resource_packs/` - Resource pack with textures and models
- `scripts/` - TypeScript source code
- `lib/` - Compiled JavaScript output
- `dist/` - Bundled distribution

## Development

```bash
npm install
npm run build
npm run local-deploy
```
